# Evidence product configuration and owned startup drain

The installed Evidence target receives only the immutable engine factory profile, losing the producer's selected Book binding even though its current public renderer has composed it. A Vector update also reproduced a Windows replacement rollback: the exact old Evidence daemon did not exit inside its two-second wait, then exited shortly afterward and allowed a proper public retry. Neither problem justifies dropping identity/resource/provenance gates or mutating private leases.

This concerns E-O1/E-O2/E-O3, E-P5/E-P6/E-P14, E-A3/E-A5, suite G-O1/G-O2 and C08/C09/C10. Trustworthy resumable evidence needs an exact usable product composition and truthful terminal lifecycle observation. Engine ownership, clean resource intervals, identity and historical evidence remain hard constraints. Conditional usefulness is subordinate to those gates; native operational clock execution is not population timing or strength qualification.

Handoff candidates: replicate Book semantics in Evidence (rejected: competing authority); read an old generated profile file (rejected: stale transaction state); continue manual selected option patches (temporary only); consume fresh engine public configuration through the Installer's declared dependency source while matching immutable launch and policy authority (selected). Existing v2 target admission still validates inventory, scalar options and clock baselines. Generated Book binding values remain opaque. Factory-profile compatibility remains available; malformed present fresh output fails.

Drain candidates: force-kill or remove ownership/leases (rejected: no exact terminal authority); declare delayed teardown successful (rejected: false replacement safety); retain repeated rollbacks (safe but leaves an avoidable operational failure); separate a finite ten-second Windows startup join from the existing two-second native query interval (selected). Every query receives at most its remaining two-second budget. Exact absence or PID reuse qualifies exit; unverifiable and late observations fail. No forced kill or private reclamation is added, default/Linux waits remain two seconds, and foreground two-second preemption is unchanged. The new bound is an explicit reviewed lifecycle contract amendment, not a hidden operator override or a claim that every shutdown finishes within it.
